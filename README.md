# AVM project page

This repository holds the code and media behind the public project page of
AVM (Autoregressive View Model), [arXiv:2611.23417](https://arxiv.org/abs/2611.23417):
https://autoregressive-view-model.github.io/

To preview it locally, run `python3 -m http.server 8000` in the repository root and open
http://localhost:8000/.

Small helpers for preparing media and cache tags are in `tools/`.
