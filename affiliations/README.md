# Affiliation icons

- `meta.svg`: colored infinity symbol from the report’s `assets/logometa.pdf`, converted to SVG with Poppler and cropped through its viewBox. Original vector colors and gradients are retained.
- `oxford.svg`: Oxford-blue crest from the supplied report asset `assets/logooxford.png`, embedded unchanged and cropped through the SVG viewBox.

Names remain HTML text, followed by their affiliation superscripts.
